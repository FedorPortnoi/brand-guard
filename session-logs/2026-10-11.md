## Traps learned (each with the fix)

- **Instagram app shell**: every post looks "readable" without a login → judge social pages only by post metadata
  (`shows_post`).
- **Instagram redirects profiles to `/accounts/login/`** → `final_url` never follows a redirect into a login page
  (`LOGIN_PATH`).
- **TikTok refuses yt-dlp** ("Unexpected response from webpage request"; wants browser impersonation) → public oEmbed.
- **Perceptual hashes can't see one changed line of text** → compare video frames by changed pixels.
- **Brave rate limit** under fast back-to-back searches can make a lookup come back empty → re-run singly before
  calling it a bug.
- **Shell heredocs eat backslashes** in Windows paths and regexes (`\b` became a backspace in a test; `D:\brand…` in
  the plan note). Use raw strings / the Edit tool for anything with backslashes; re-read what was written.
- **`monkeypatch.undo()` inside a test** also undoes the autouse fixture that points tests at a temporary log → the
  test read the real `data/investigations.db`. Never call `undo()` in a test; restore by hand.
- **`tmp/` in the repo is not git-ignored** → sample files live in `D:\brand-guard-samples\`; commit named files only.
- **Local check log fills with test runs** → crowd counts on the laptop are inflated; Replit starts clean.
- **Terminal chat**: drag-and-drop doesn't work on the owner's machine; links copied out of it show `]8;;…` (display
  only).
