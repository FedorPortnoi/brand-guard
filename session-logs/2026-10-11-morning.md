## Traps learned (each with the fix)

1. **"Replit at step 1" was never true.** The Repl was imported, never set up or published. Check the Repl's
   Publishing panel, not the notes. First publish needs a paid Reserved VM.
2. **The agent doesn't read `.env`.** Start it with
   `node node_modules/tsx/dist/cli.mjs --env-file=../.env src/agent.ts` (from `imessage-agent`), or it opens the
   terminal chat. `npx tsx --env-file` works too but leaves more wrapper processes.
3. **Stopping a background shell leaves its children running** (uvicorn, node). Two agents on one Spectrum project
   would both answer. After a stop, kill by command line (`Get-CimInstance Win32_Process` matching `agent.ts` /
   `uvicorn`) and confirm port 8000 is free.
4. **iMessage sends a link and its caption as two messages.** Handled by `SETTLE_MS`; replies arrive ~2 s later.
5. **`curl | python` on Windows shows UTF-8 as cp1252** (`®` → `Â®`). Check code points (`ascii()` / JSON escapes)
   before calling it a bug.
6. **Shell heredocs eat backslashes** (again: `\s`, `\n` in Python/regex). Use the Edit tool for code with backslashes.
7. **`python -c` without `import app.main` doesn't load `.env`**, so Brave has no key and search falls back to
   DuckDuckGo (blocked): empty results that look like a bug.
8. **The venue network re-signs `trycloudflare.com` (Fortinet).** Use a phone hotspot; don't work around it.
9. **Chrome-extension screenshots time out when the tab is in the background.** Render with headless Chrome instead:
   `chrome --headless=new --hide-scrollbars --user-data-dir=<scratch> --window-size=1672,941
   --virtual-time-budget=8000 --screenshot=<file> http://127.0.0.1:8000/` (run from PowerShell; from Git Bash it
   exited without a file).
10. **A maximized Chrome window ignores resize.** The 390 px iframe trick worked, but the new `X-Frame-Options: DENY`
    header blocks it now; use headless Chrome with `--window-size=390,844`.
11. **The section-scoping test caught CSS comments as selectors.** Strip `/* … */` first.
12. `cloudflared`'s only tunnel, `4kub`, is the CRM's. Don't touch it.
